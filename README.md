# Intelligent Travel Recommendation System

A web application developed with **Java and Spring Boot** that helps users discover tourist destinations based on their preferences and travel requirements.

The system combines personalized recommendations, geographical distance calculation, and an AI-powered travel assistant to make trip planning easier and more interactive.

## Features

- User registration and authentication
- Browse and manage tourist destinations
- Personalized destination recommendations
- Search based on budget, distance, duration, travel type, and season
- AI travel assistant powered by Gemini API
- Geographical distance calculation using the Haversine formula
- Save and manage favorite destinations

## Technologies

- Java 21
- Spring Boot
- Spring MVC
- Thymeleaf
- HTML, CSS, JavaScript
- PostgreSQL
- Spring Data JPA
- Maven
- Gemini API
- Nominatim / OpenStreetMap

## How It Works

Users can either manually enter their travel preferences or describe their requirements through the AI travel assistant. The system processes these parameters and generates personalized destination recommendations using a rule-based recommendation mechanism.

## Future Improvements

- Machine learning for improved personalization
- Real road distance and route calculation
- Real-time weather and travel information
- Additional AI assistant capabilities
